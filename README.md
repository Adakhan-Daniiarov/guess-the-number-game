# Guess the Number Game

A classic, interactive command-line game built with **Python** where the player tries to guess a randomly generated number. 

## 🎮 How It Works
1. **Choose Difficulty:** At the start of the game, you select your preferred difficulty level. This determines the range of the hidden number:
   * **Easy:** Range from 1 to 50
   * **Medium:** Range from 1 to 100
   * **Hard:** Range from 1 to 500
2. **Make Guesses:** The game generates a random number within that range, and you start guessing.
3. **Smart Hints:** After each guess, the game gives you instant feedback, telling you whether your guessed number is **too big** or **too small**.
4. **Win the Game:** The game continues until you find the exact correct number!
